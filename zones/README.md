# Skynett zones

Current 69-zone Skynett set, exported on 14 October 2026 from the active WPF profile. The application release does not bundle this set. This download contains zone polygons, outline/fill colours and layer metadata; no personal waypoints, death markers, settings, imports or player reports are included.

Download **Skynett-Zones.zip** from the v2.0.0 release, extract it, then open **Settings → Zone Creator → Import file** and choose `zones/skynett/zones.tsv`. Back up your existing zones first. Import through the wizard rather than overwriting your AppData files. Open Custom map zones in the tactical sidebar and enable the Skynett layer and the zones you want.
