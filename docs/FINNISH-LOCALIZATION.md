# Finnish (Suomi)

Select **Suomi** in the language menu. The saved language code is `fi`; `fi-FI` also resolves to Finnish. The enum value is appended so earlier saved language choices retain their meaning.

The Finnish catalogue explicitly covers 787 interface messages, 16 map sections, 48 map categories, 242 map object types, 2,328 spawn item IDs and 136 item categories/property labels. Generated map names translate their type while keeping sector codes and place names. Personal waypoints, group names, model/brand names, Latin species names, command tokens and item IDs retain their identity. Unknown custom map labels keep their original text.

Finnish item labels were authored using explicit noun and variant tables. General machine-translation drafts were rejected for weapon and item terminology; the shipped resource is a finite reviewed table with no translation service or model dependency. Search accepts Finnish with or without ä/ö accents and retains English names and raw IDs. Switching language refreshes existing selections and cart rows without changing commands.

Terminology: **sijaintimerkki** is a saved location marker; **reittipiste** is a route stop; **peittävyys** is opacity; **lipas** is a weapon magazine; **kiikaritähtäin** is a scope; **äänenvaimennin** is a suppressor. Fish include isobassi (bass), hammasahven (dentex) and kultaotsa-ahven (orata).

The optional **Noora (Suomi)** navigation pack contains 12 speech-synthesized Finnish clips generated with Microsoft's fi-FI-NooraNeural voice. It is embedded and plays locally without a speech service connection. Distance clips say “viidensadan / kahdensadanviidenkymmenen / sadan / viidenkymmenen metrin päästä”, followed by the action. No standalone English “In” prefix is used. The pack also says “Lasketaan uusi reitti” on recalculation. Existing voice preferences remain independent of the interface language.

Automated coverage, placeholder parity, culture selection, map composition, accent-free search, live switching, command preservation and voice composition are checked. Visual previews cover the current Windows environment. Independent native-speaker approval is still pending; structural coverage is not a native-speaker certification.
