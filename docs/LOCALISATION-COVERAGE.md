# Text localisation

The application includes English, Argentine Spanish, French, German, Dutch, Russian, Simplified Chinese, Turkish, Arabic, Brazilian Portuguese, European Portuguese, Korean, Polish, Thai, Traditional Chinese, Japanese, Czech, Italian and Ukrainian.

All catalogues include the interface, map categories and built-in names, player/admin/spawn tools, 2,328 item names and spawn headings. Custom names and technical identifiers are preserved. Text resources are bundled; runtime translation services are not used. Catalogue/placeholder regressions run during the build. Native-speaker wording review remains pending.

Recorded navigation audio is available in four supplied voice packs; text-language coverage does not imply matching recorded audio for every language.
