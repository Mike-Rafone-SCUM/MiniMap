# SCUM MiniMap releases

SCUM MiniMap is a tactical overlay for SCUM, made for the Skynett community. This repository hosts application updates.

## First installation

Download from [itch.io](https://mikerafone.itch.io/skynettminimap-tactical-real-time-overlay-for-scum).

## Updates

Version 1.2.4 and later check this repository for newer stable releases. Use **Check for updates (GitHub)** in Settings or the tray menu. Git and a GitHub account are not required.

Accept the download and choose a new filename. The app verifies the SHA-256 checksum before saving the update. Exit MiniMap from its tray menu, replace the old executable with the downloaded file, then run it. Your saved settings and zones are retained.

[Latest release](https://github.com/Mike-Rafone-SCUM/MiniMap/releases/latest)

Users of 1.2.3 and earlier must install the migration build once to enable GitHub updates.

## Release contents

Each stable release is tagged `vX.Y.Z` and includes `SkynettMiniMap.exe` and `update.txt` (version and SHA-256 checksum). Publish as latest only after both assets have uploaded. Publish a new version instead of replacing existing executable assets.
